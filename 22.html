Termodinamikaning birinchi qonuni

9-sinf fizikasi · 22-mavzu · animatsion simulyatsiya, video-dars, savol va topshiriqlar

Asosiy tushuncha

Gaz isitilsa, uning molekulalari tezroq harakatlanadi, ya’ni ichki energiyasi ortadi. Gaz kengayib, porshenni itarsa, ish bajaradi. Berilgan issiqlik ana shu ikki yo’lga sarflanadi.

Q = ΔU + AQ — sistemaga berilgan issiqlik (J), ΔU — ichki energiya o’zgarishi (J), A — sistema bajargan ish (J)

Qonun: sistemaga berilgan issiqlik miqdori uning ichki energiyasini o’zgartirishga va sistemaning tashqi jismlar ustida ish bajarishiga sarflanadi. Bu energiyaning saqlanish qonunining issiqlik hodisalaridagi ko’rinishidir.

Ishoralar: Q > 0 — gaz issiqlik oladi, Q < 0 — beradi. A > 0 — gaz kengayadi (ish bajaradi), A < 0 — siqiladi. ΔU > 0 — gaz qiziydi, ΔU < 0 — soviydi.

Simulyatsiya: gaz, porshen va issiqlik

Pastdagi sirg’aluvchilar bilan issiqlik Q va ish A ni o’zgartiring. Molekulalar tezligi ichki energiyaga, porshen holati ishga bog’liq. Yoki tayyor jarayonni tanlang.

Savollar

1. Termodinamikaning birinchi qonuni qanday ifodalanadi?

Q = ΔU + A: berilgan issiqlik ichki energiyani o’zgartirishga va ish bajarishga sarflanadi.

2. Gaz hajmi o’zgarmasa (A = 0), berilgan issiqlik nimaga sarflanadi?

Hammasi ichki energiyani oshirishga: Q = ΔU. Gaz qiziydi.

3. Issiqlik almashinuvisiz (Q = 0) gaz kengaysa, harorati qanday o’zgaradi?

Pasayadi. Ish ichki energiya hisobiga bajariladi: ΔU = −A.

4. Velosiped shinasini nasos bilan shishirganda nasos qizishining sababi nima?

Havoni siqishda ish bajariladi (gaz uchun A < 0), ichki energiya ortadi va havo qiziydi.

5. Ichki energiyasi o’zgarmasa (ΔU = 0), Q va A orasida qanday bog’lanish bor?

Q = A: olingan issiqlikning hammasi ishga aylanadi.
